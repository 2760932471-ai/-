# V0.10 页面结构调整

用户确认名称：**工作应用、数字员工、知识库、AI基础能力配置**。供应商资料导入 / 登记、授权接口和同步放入 AI基础能力配置。此次复用已有功能，不把移动入口描述成接通了新的供应商或模型。

## 页面与点击行为

| 入口 | 内容 | 点击后的动作 |
| --- | --- | --- |
| 工作应用 | 5 个内容制作应用，4 个经营 / 服务工作包 | 内容应用打开资料表，生成后进入交付物；经营应用装配相应员工并打开新建目标 |
| 数字员工 | 已创建员工、岗位模板与装配能力 | 可交目标、配置、试运行或创建员工 |
| 知识库 | 文档导入、切片、索引、召回测试 | 保存文档后关键词索引可用；向量模式仍需配置 Embedding |
| AI基础能力配置 → 模型连接 | 本机 Codex 与兼容 API | 添加或编辑连接，测试后才可用于模型员工；新增连接表单优先本机 Codex，未自动使用订阅 |
| AI基础能力配置 → Skill 配置 | 已实现的代码与外部能力 | 输入测试资料，查看运行结果 |
| AI基础能力配置 → 外部 Agent | Dify / 只读 HTTP 接入 | 配置协议、字段权限、凭据变量，按当前版本测试 |
| AI基础能力配置 → 供应商接入 | 来源配置、正文与链接登记、授权接口同步、资料审核 | 添加来源 → 手动登记或授权 HTTP 配置 → 保存 → 手动同步 → 审核 → 在匹配目标中选用 |
| AI基础能力配置 → 建设进度 | 134 项方案能力与实现边界 | 筛选规划 / 部分实现 / 限定实现；可测试已关联 Skill，不直接执行规划能力 |
| AI基础能力配置 → 旧版适配器 | 原规则与 HTTP Agent | 保留配置与历史流程入口 |

协同工作台、任务中心、运行记录继续使用原有数据。供应商来源资料不会因入口移动自动进入知识库；需要切片召回时须导入已核验正文。资料登记支持粘贴正文和图片 / 商品链接，没有新增文件解析或原生 1688 抓取。

## 导航与历史兼容

桌面侧栏：协同工作台、工作应用、数字员工、知识库、AI基础能力配置、任务中心、运行记录。

手机底部：协同工作台、工作应用、数字员工、知识库、更多。“更多”弹窗提供 AI基础能力配置、任务中心、运行记录；点击后关闭弹窗并进入目标页面。Esc 或关闭按钮收起弹窗。

配置子页保存在 hash，例如 `#ai-config/sources`。刷新或浏览器返回后仍落在相同子页；未知子页回到模型连接。旧书签自动转向：

- `#capabilities` → `#applications`
- `#connections` → `#ai-config/models`
- `#agents` → `#ai-config/legacy`
- `#sources` → `#ai-config/sources`

目标资料页的“管理知识库”“管理来源”分别跳到对应新入口；员工页的工作入口跳到工作应用。数据存储 key、服务端结构、请求接口均未改变，不需重置会话。

## 失败和未接通状态

模型、供应商来源、外部 Agent 的未配置、待验证、同步失败等状态照常显示；移动入口不会自动授权或发起同步。保存配置仍不自动拉取外部资料。静态预览只验证本地交互，HTTP 同步与真实模型需完整后端及客户授权。
