# 内置知识库 · V0.5

本版在平台内部保存文档、切片和索引，提供检索召回与员工引用。无需先购买或连接外部知识库。V0.4 的“供应商与外部来源”继续管理外部链接、素材与授权，两者用途不同。

## 一、使用流程与点击行为

入口：**能力中心 → 知识库**。

1. **新建知识库**：输入名称与说明，如“商品知识”“售后政策”。保存后进入该库范围。系统提供一个空的“企业知识库”，不注入虚构经营资料。
2. **导入文档**：选择本机 UTF-8 TXT / Markdown 文件，或直接粘贴正文。文件只会先填入表单，尚未上传保存。填写标题、来源说明；商品专用文档填写 SKU，通用规范留空。
3. **预览切片**：设置切片长度（200–1600）和重叠长度（0–切片长度的一半），点击预览。默认 700 / 100，优先在段落或句末断开。逐片展开可查看原文和位置。修改正文或参数后清除旧预览，避免把旧切片当成当前结果。
4. **保存并切片入库**：确认文档可供员工参考，保存正文和切片，立即可以 BM25 检索。没有先调用大模型，也没有偷偷调用 Embedding 服务。
5. **查看切片**：显示当前版本全部切片；“编辑与重切片”保存后文档版本增加、切片编号重建、旧向量索引失效。停用文档后不再参与新召回，历史记录仍保留。
6. **召回测试**：输入问题，选 BM25 / 向量 / 混合模式、Top K、可选 SKU。点击后展示算法名称、检索切片数量、命中正文、分数、文档版本、切片编号和来源。这里只展示检索结果，不冒充生成式问答。
7. **目标 → 资料 → 知识库自动召回**：选择该目标允许使用的库、召回方式和数量，保存后重新确认计划。新建团队目标默认选中启用的“企业知识库”，旧目标不强行更改范围。可先“按当前目标测试召回”。
8. **员工执行 / 群聊回复**：在执行员工前，按本次群聊提问（优先）或目标正文检索所选库，并限定当前 SKU 或通用知识。召回切片进入模型 / 代码员工的输入；运行记录保存查询、算法、命中与来源。代码型“任务交付摘要”和“详情页大纲”会列出引用，模型员工收到引用要求。

未启用知识库或没有相关切片，不会凭空补足参数、安装条件或售后政策。规则员工不做语义理解或自行消解冲突，模型文字仍需核验。知识引用不能直接覆盖商品事实卡或授权发布业务操作。

## 二、三种召回方式

| 方式 | 实际实现 | 前提 |
|---|---|---|
| BM25 | 按词频、逆文档频率和长度归一化评分；中文使用相邻双字词，英文与 SKU 使用词项 | 保存文档后即可使用，无外部模型 |
| 向量 | 将文档切片和问题交给 Embedding 接口，存储真实向量，用余弦相似度排序 | 配置服务，且所选范围文档全部完成对应模型的向量索引 |
| 混合 | 分别计算 BM25 与向量排名，通过 RRF（k=60）融合 | 与向量模式相同 |

Top K 为 1–8。BM25 只返回正分匹配，分数不是正确率；向量默认最低相似度为 0.3，服务端搜索接口可指定 0–1 的 `minSimilarity`。不同模式分数不能直接比较。没有召回时显示明确空结果，不拿无关片段凑满 Top K。

BM25 是词项匹配，不能保证同义词召回。当前没有重排模型、查询改写、图片理解、表格专用检索或人工纠错学习。

## 三、Embedding 配置与索引

可使用提供 OpenAI 兼容 `/embeddings` 协议的授权服务，包括自行部署并提供该协议的模型服务。当前服务端只允许白名单中的公网 HTTPS 域名；内网直连需另行建设。配置只写在服务器环境中，不在聊天中发送密钥：

```dotenv
KB_EMBEDDING_ENDPOINT=https://your-provider.example.com/v1/embeddings
KB_EMBEDDING_MODEL=你的嵌入模型标识
KB_EMBEDDING_KEY=你的接入密钥
AGENT_ALLOWED_HOSTS=your-provider.example.com
```

保留已有 `AGENT_ALLOWED_HOSTS`，以逗号追加域名；云环境网络策略也须允许该域名。ChatGPT Plus / Pro 订阅不能直接作为 Embedding API 额度；本地 Codex 桥接仍用于员工生成，不代替嵌入服务。

配置完成后，进入文档卡片点击 **构建向量索引**。每批最多 16 个切片，界面显示索引进度。成功后保存模型标识、维度和索引状态；失败不提交半份向量，BM25 继续可用。切片向量输入为“文档标题 + 切片正文”，检索问题使用相同接口和模型。

接口要求：POST `{model,input:[文本…],encoding_format:"float"}`，Bearer 密钥，返回 `{data:[{index:0,embedding:[数字…]},…]}`。每批请求超时 20 秒，不跟随重定向，响应上限 2MB；维度 1–4096，数量、下标、非零性、维度和有限数值均校验。正文会发送给所配置的 Embedding 服务；只有主动构建向量索引或使用向量 / 混合召回时发送。

更换模型或接口后，旧索引显示需重建。检索范围内还有未完成索引时，向量 / 混合模式明确报错，不悄悄降级为 BM25。

## 四、异常与版本一致性

| 情况 | 产品处理 |
|---|---|
| 文件类型不支持、UTF-8 无效、内容太大或二进制内容 | 表单提示错误，保留原有输入，不创建文档 |
| 参数无效或正文为空 | 拒绝预览 / 保存，提示长度与重叠规则 |
| 同时编辑同一文档 | 旧 revision 返回 409，重新打开当前文档后编辑 |
| 索引过程中修改文档或更换模型 | 后续批次停止，旧索引结果不覆盖新版本 |
| 索引请求失败或超时 | 标为失败，保留正文与 BM25；可重试 |
| 服务重启中断索引 | 标为失败，用户可重新构建 |
| 文档 / 知识库停用 | 新检索立即排除；进行中的引用在下一执行检查及结果写入前校验，失效引用拒绝交付 |
| 交付后，引用文档改动或停用 | 验收检查会阻止接受过期引用；应创建跟进目标重新检索与交付，历史成果不抹除 |
| 召回问题为空 / Top K 超出范围 | 拒绝查询，保留表单 |
| 没有命中 | 返回空 hits，说明没有知识依据 |
| 静态预览使用向量模式 | 不可用；仍可导入、切片、BM25 检索与规则员工引用 |

文档检索结果是数据，不是能改变系统或员工权限的指令。引用只证明“来自哪个文档”，不证明客户录入内容本身正确。

## 五、接口与存储

- `GET /api/knowledge`：知识库、文档摘要、Embedding 配置就绪标记；不返回密钥或向量。
- `POST /api/knowledge/bases`、`PUT /api/knowledge/bases/:id`：库设置。
- `POST /api/knowledge/documents`、`PUT /api/knowledge/documents/:id`：正文、来源、SKU、切片参数、启用状态、确认标记；更新传 revision。
- `GET /api/knowledge/documents/:id`：正文及切片（不返回向量）。
- `POST /api/knowledge/preview`：预览切片，不保存。
- `POST /api/knowledge/documents/:id/index`：构建向量索引，传 revision。
- `POST /api/knowledge/documents/:id/toggle`：启用 / 停用，传 revision、enabled。
- `POST /api/knowledge/search`：`query`、`baseIds`、`mode`、`topK`、可选 `sku` / `minSimilarity`。
- `POST /api/goals/:id/actions`：`kind:"knowledge"`、`expectedVersion`、`knowledge:{baseIds,mode,topK}`。

完整后端把正文、切片和向量保存到本机 `.data/platform.json`，规则检索在单进程内完成；预览保存在当前浏览器。无需外部知识库或向量数据库。

这是有容量限制的开发版：最多 20 个库、100 份文档、1000 个切片；单文件 256KB，单正文 80000 字符；切片位置按 JavaScript 字符串偏移记录。当前没有数据库倒排索引、近似最近邻向量数据库、后台持久队列和多租户文档权限。大规模上线应迁移持久数据库 / 向量索引，并补上团队权限与后台索引队列。

## 六、尚未覆盖与验证口径

支持 TXT / Markdown 和正文粘贴；PDF / Word / 扫描件解析、OCR、图像向量、图片生成尚未实现。外部来源同步得到的资料不会自动入此库，需要先核验，再导入正文；后续可建设审核后的自动入库流程。

自动检索使用目标或人类最新提问，没有让模型任意联网搜集资料，也尚未提供模型自主多轮改写检索问题的工具。

自动化验证覆盖切片边界、BM25 命中与空结果、持久化、范围过滤、向量 / 混合排序、索引更新竞态、员工引用和传输校验。向量测试使用受控嵌入响应，尚未配置客户真实 Embedding 服务，不宣称已经验证其语义效果。
