# V0.14 工作空间、知识与外部连接

## 这版能做什么

- 消息操作变为回箭头图标 +「引用」，点击后仍在输入框上方显示引用摘要。
- 「协作进度」改为「分工与执行状态」，解释谁负责、当前步骤和负责人需要处理的事。待输入或失败明确显示受阻，避免显示成正在顺利交接。
- 工作空间可创建、改名、切换。各空间的目标、对话、员工、知识库、搜索和店铺配置独立保存；刷新后保持所选空间。默认改为「我的工作空间」，旧资料保留，不改写历史消息。
- 知识文档可删除，连同切片与向量一并移除；历史交付中的引用保留历史信息，但执行或验收时不能继续使用已删除来源。非空知识库不能直接删除；空库可删除。
- 知识库提供六份通用工作指引，可预览修改、确认后导入；也提供可单独上传的 Markdown 文件。
- 新增网络搜索配置：Tavily 或只读远程 MCP。测试成功后，选品资料不足时总控会自动搜索；可以限定 1688 站点。网页摘要是待核验线索，不直接作为已确认报价或店铺指令。
- 新增店铺登记与只读授权网关检查，优先说明淘宝 / 天猫、抖店的接入方式。创建目标可关联已登记店铺，始终保留草案执行边界。

## 工作空间交互

点击侧栏空间名称或顶部空间名称，打开空间列表。输入新名称后「创建并进入」；已存在同名空间、名称为空或超长会显示错误。点击「改名」后保存名称，不移动资料。进入另一个空间会重新加载页面，目标、知识与连接读取新空间数据。

服务端默认空间继续使用原 .data/platform.json，新增空间位于 .data/workspaces/<id>/platform.json，目录保存在 .data/workspaces.json。浏览器预览保留原默认空间存储键，其他空间使用独立键。

当前是一个管理员管理的多个工作空间，不包含成员邀请、租户级身份授权、独立 API Token、权限分级或企业审计。部署时仍需设置 PLATFORM_TOKEN，不能当成已经完成多租户系统。

## 网络搜索接入

入口：AI基础能力配置 → 网络搜索。

### Tavily

1. 在你使用的搜索服务账户中取得 API Key。
2. 将密钥写入运行平台的服务器环境变量，例如 SEARCH_SECRET_PRIMARY；不要写进知识文档、源码或聊天。
3. 在原 AGENT_ALLOWED_HOSTS 后追加 api.tavily.com，不要覆盖已有域名。
4. 页面选择 Tavily，填写密钥变量名称，勾选启用与只读，保存。
5. 输入搜索词并「测试连接并搜索」。成功后总控可自动调用；搜索费用属于该搜索服务账户，与 ChatGPT 订阅分开。

### MCP

支持远程 Streamable HTTP，JSON 或 SSE 响应。填写 HTTPS endpoint、只读搜索工具名称、query 或 q 参数名及可选密钥变量。连接依次 initialize → notifications/initialized → tools/list → tools/call。每次只调用配置的工具；工具声明 destructiveHint=true 或 readOnlyHint=false 时拒绝使用。不启动本地 stdio 进程，不支持任意命令执行。

结果需为 structuredContent.results，或文本块内 JSON results 数组；每项有 title、url、content / snippet。返回普通散文但没有结构化链接的 MCP 不会被误判为搜索成功。当前是这个明确协议范围的适配，不保证兼容所有搜索 MCP。

1688 模式在查询中附加 site:1688.com，并过滤返回链接的主机名。它只能找公开网页，不能获取登录态采购数据、证明供应商资质或获得 1688 交易权限。

### 总控调用与异常

新建选品目标先查本地文档和已核验来源；不足时，已启用且测试通过的搜索连接自动运行。会话里提及全网 / 1688 / 搜索也会进入查找。无品类时先澄清目标。查询结果展示标题、链接、摘要和采集时间，并进入本轮员工输入中的 webResearch，但不能覆盖已确认业务事实。

同配置、同查询、同站点五分钟内复用结果；修改配置后须重新测试。超时、错误响应、未授权域名、缺密钥或格式不符不会返回伪造结果。查找期间目标或配置变更，旧结果不用于新目标。最多保留最近十次查询，每次最多八条线索。

服务器实际搜索尚需服务账户 / MCP 地址、有效凭证和允许网络访问。本次使用受控接口替身验证协议及自动路由，没有声称完成真实全网或 1688 商品检索。

## 店铺接入与上下架边界

入口：AI基础能力配置 → 店铺连接。

1. 添加店铺名称、平台、公开地址和店铺 ID。仅登记时显示「待授权」。
2. 淘宝 / 天猫通过其官方开放平台应用或已授权服务商完成授权；抖店通过抖店开放平台应用或已授权服务商完成授权。不同平台的资质、权限、审核要求以官方当前规则为准。
3. 已有授权网关时填写只读接口地址与 STORE_SECRET_ 开头的密钥变量名；域名加入 AGENT_ALLOWED_HOSTS。
4. 点击「检查授权」校验实际返回的店铺 ID、权限及有效期。失败、配置修改、停用或授权过期不能显示为有效连接。
5. 新建目标第二步可以关联店铺，自动带入店铺名称。只关联当前空间启用的店铺，不能跨空间引用。

网关契约：POST 配置的 HTTPS endpoint，Authorization: Bearer <服务器变量值>。

```json
{"schemaVersion":1,"operation":"connection_status","platform":"taobao","shopId":"实际店铺ID"}
```

示例返回（仅协议示意）：

```json
{"schemaVersion":1,"connected":true,"shopId":"实际店铺ID","scopes":["product.read"],"expiresAt":"2030-01-01T00:00:00Z"}
```

**这版没有淘宝 / 天猫、抖店原生 OAuth 回调及实际商品读写适配。** 网关身份检查成功也不意味着上下架可用。接管店铺还需平台授权、读写 API 适配、商品映射、逐次审批、幂等提交与平台状态回查；当前只允许生成草案。不要把前台店铺网址填为授权接口，也不要上传账号密码或 Cookie。

## 知识模板与删除

六份内容包括选品研究、商品事实、内容审核、客服流程、上下架检查和经营指标。模板提供通用工作方法，不包含真实商品、报价、退货期限、运费承诺或采购授权。模板导入仍需核对并确认，店铺政策要另行补充。

删除文档前确认标题与影响；取消时不做修改。文档正在向量索引或版本已变更时拒绝删除。删除空库时从目标检索范围移除；不删除目标或已有对话。

## 验证

自动化覆盖：空间隔离与持久化、知识删除和引用失效、搜索测试门槛/缓存/域名过滤、MCP 握手与工具调用、配置并发变更、店铺身份匹配、草案边界、外部请求目标与凭证保护。

浏览器分别验证免安装预览和完整后端：创建 / 改名 / 切换空间，模板预览导入、取消和确认删除，搜索配置、店铺平台说明、目标关联、引用文字和手机无横向溢出。原有聊天上下文、@ 全员和内容工作流继续回归。
