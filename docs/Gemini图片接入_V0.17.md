# Gemini 图片接入 · V0.17

本次增加 Google Gemini 原生图片接口。已有 OpenAI Images 配置继续使用，不自动覆盖。

## 在哪里操作

进入「AI基础能力配置 → 图片生成」，选择「Google Gemini · 原生生图」。页面自动填入官方地址、图片模型示例与密钥变量名；模型可按实际项目权限修改。

1. 将 API Key 保存到服务器私密环境变量 `IMAGE_SECRET_GEMINI`，不要填进网页、聊天、仓库或 URL。此前若已在聊天中发过密钥，应在 Google AI Studio 撤销并重建。
2. 服务器设置 `PLATFORM_TOKEN`，用于本平台登录。将 `generativelanguage.googleapis.com` 加入 `AGENT_ALLOWED_HOSTS` 和部署环境网络白名单，保留原有域名。参考图所在 CDN 也需加入白名单。
3. 本地可从 `.env.example` 创建不提交到 Git 的 `.env`，填写后运行 `node --env-file=.env src/server.js`；云环境私密变量须经保存、发布和重新加载后才生效。保存配置草稿不等于已应用。
4. 页面启用并保存生图连接。点击「检查 Gemini 连接」，只读取模型元数据，不提交生成任务。成功仅说明密钥能访问该模型，不保证图片输出权限或剩余额度。
5. 进入「工作应用 → 生成主图 / 详情图」，输入画面描述、选择比例并确认生成；也可从图片目标中的「生成图片」进入。无需底图即可生成概念图。参考商品图模式需要选择已审核并获授权的素材。
6. 任务从等待生成到正在生成，再到成功、失败或结果未确认。成功后可查看、下载 PNG；任务和知识引用保存在当前工作空间，目标内发起的图片同步成为交付物。

GitHub Pages 仅展示交互，不能存放密钥或执行后台生图。完整后端运行在你的电脑或服务器，API 额度归属对应 Google 项目，与 ChatGPT Plus/Pro 订阅无关。

## 协议与异常

- 通过 `x-goog-api-key` 请求头认证；原生端点为 `https://generativelanguage.googleapis.com/v1beta/models/{model}:generateContent`。
- 示例模型 `gemini-2.5-flash-image` 可修改，不承诺是最新型号或在所有项目中可用。
- 输入文字，以及可选的 `inlineData` 参考图；请求 `TEXT`、`IMAGE` 输出，按 1:1、2:3、3:2 指定比例。Gemini 实际像素以返回图片为准。
- 只保存有效 PNG 图片；仅有文字、被内容审核拦截、非 PNG 或格式异常时不会把文本简报伪装成图片。
- 网络中断、超时、部分服务端错误按“结果未确认”处理，不自动重复提交，避免可能重复消耗额度。
- API 响应如包含密钥会被拒绝；错误界面不展示原始服务响应。参考图下载不附带 API Key。
- 改动配置后连接检查失效；等待中的旧配置任务停止，不偷偷使用新服务。生图仍可能产生服务商费用，即使结果需要人工核对或未能保存。
