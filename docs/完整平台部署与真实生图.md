# 从静态预览切换到完整平台

`https://2760932471-ai.github.io/-/` 是静态 HTML 预览，不能保管服务器密钥、运行后端或调用 Gemini。更新预览版本不会改变这一点。需要创建另一个运行完整 Node 后端的网址。

## 已准备：Render 部署配置

仓库根目录 `render.yaml` 定义单实例 Node 服务、HTTPS 托管健康检查、持久化磁盘、平台访问令牌和 Gemini 密钥变量。未替用户创建 Render 账号、服务或支付费用，尚未真实部署验证。Starter 与磁盘为付费资源，创建前请核对平台当前价格；当前 JSON 存储仅适合单实例。

[打开 Render 部署入口](https://render.com/deploy?repo=https://github.com/2760932471-ai/-)

1. 登录 Render，连接并授权访问本 GitHub 仓库，创建 Blueprint，选择 `main` 分支并读取 `render.yaml`。如果部署链接未自动选仓库，在控制台 New → Blueprint 手动选择。
2. 在 Render 的私密变量输入框中填写**重建后的** `IMAGE_SECRET_GEMINI`，不要填到源码、聊天或预览网页。配置中的 `sync: false` 表示创建服务时要求用户安全输入。
3. 核对 Starter 与磁盘费用后，再由你点击创建 / 部署。默认关闭后续自动部署，避免 GitHub 代码更新直接影响实际运行。
4. 等服务显示成功，打开 Render 给出的 `https://…onrender.com` 网址。到该服务 Environment 中取得自动生成的 `PLATFORM_TOKEN`，用它登录本平台的访问令牌输入框；不要发送到聊天。服务所有用户共享此令牌，尚不提供企业多用户权限体系。
5. 进入 **AI基础能力配置 → 图片生成**，选择 **Google Gemini**，密钥变量名保留 `IMAGE_SECRET_GEMINI`。确认你项目可用的图片模型名称，启用并保存，然后检查连接。此检查只读取模型信息，不发起生图。
6. 回到协同工作台，发送“生成一张银色花洒白底概念主图”，在图片任务卡点击确认。成功后可打开 PNG，结果也在目标交付物中。失败时按卡片中的状态检查模型权限、额度或服务网络，勿反复点击产生新任务。

工作应用里的“生成主图 / 详情图”同样可用；如果要保持实物外观，选择已审核授权的商品参考图。当前允许域名只有 Google API，使用图片 CDN、搜索、店铺接口或其他服务前，需要把相应域名**合并**到 `AGENT_ALLOWED_HOSTS`，再配置对应授权。

## 已有服务器也可以部署

使用 Node.js 22+，下载仓库 `main`，在服务器私密环境中配置：`PLATFORM_TOKEN`、`IMAGE_SECRET_GEMINI`、`AGENT_ALLOWED_HOSTS=generativelanguage.googleapis.com`、持久化目录 `DATA_DIR`。执行 `npm start`，将 `PORT`（默认 3000）通过 HTTPS 反向代理对外提供。访问这一完整平台网址，再完成上述第 5、6 步。

## 现有预览里的数据

静态预览的目标和聊天只在原浏览器本地保存，不会自动出现在新部署的平台。可先在原目标中导出聊天记录留存；当前没有完整工作空间的迁移导入工具，不承诺一键迁移。新后端的数据和生成图片写入其持久化磁盘，仍需自行安排备份。

这里的云开发环境设置与 Render 服务环境变量也彼此独立：在其中一处填写密钥，不会自动同步到另一处。
