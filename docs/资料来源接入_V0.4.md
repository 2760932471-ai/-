# 资料与来源接入 · V0.4

本版提供可运行的资料管理、审核、目标引用和通用 HTTP 接入。没有客户系统的授权与字段映射，不能称为已接通客户知识库或 1688。图片生成尚未实现。

## 1. 用户如何使用

入口：**能力中心 → 资料与来源**。

1. **添加 / 配置来源**：选择“知识库 / 内容平台”或“供应商来源”。手动登记不联网；HTTP 模式填写适配接口和服务器密钥变量名。保存后为“接口待验证”，不会自动同步。
2. **登记资料**：选择来源，填写知识正文，或商品参考图的原图地址、对应 SKU、原始商品链接。通用品牌规范可不填 SKU，商品参考图必须填 SKU。点击“保存为待审核”，不会立即进入员工上下文。
3. **查看与审核**：查看完整正文、原图链接、来源、使用范围、有效期和上一条审核说明。原图由用户点击链接核验，本页面不自动下载或解析图片。通过审核须填写说明并勾选核验确认；未知授权、已过期或来源停用会拒绝通过。图片必须标明“已授权使用”并提供依据；知识正文可以限定为“仅供参考”。
4. **搜索**：在标题、SKU、正文、来源名称中做关键词包含匹配，可筛选来源类别和审核状态。这不是向量检索或语义 RAG。
5. **新建目标 → 资料 → 商品与参考素材**：显示同 SKU 素材及通用知识，审核无效项不可新选。最多选 8 项，勾选内容一致性确认后保存。保存会创建新的目标版本、将旧草案标为已替代，并返回待确认计划。
6. **确认计划**：规则员工的详情页大纲、任务交付摘要会列出所选资料、版本与来源；模型员工收到所选正文和图片地址，图片地址目前只作为文本引用，不代表模型已经读取图像像素。其他数值计算 Skill 仍仅使用相应的已确认字段。

选用资料不自动覆盖材质、成本、库存等商品事实，不自动解决来源冲突。用户需在商品资料表单单独核对；无法判断同款时，先不选用该素材。当前的 SKU 匹配是用户登记的编号精确匹配，不是视觉识别。

## 2. 来源连接协议

服务器需要 Node.js 22+。来源接口应由客户的 CMS / 知识库集成服务或供应商授权适配服务提供。**不能把 Dify 控制台首页、知识库网页或 1688 商品页直接作为接口地址。**

在服务器 `.env` 配置（不要提交真实值）：

```dotenv
AGENT_ALLOWED_HOSTS=cms-adapter.example.com
SOURCE_SECRET_CMS=你的实际接入凭据
```

`AGENT_ALLOWED_HOSTS` 与模型 / Agent 接口共用，已有域名应保留，以逗号追加；同时满足所在云环境的网络策略。界面只保存 `SOURCE_SECRET_CMS` 这个变量名，不保存密钥值。

平台向配置的完整 HTTPS 地址发送 POST：

```json
{
  "schemaVersion": 1,
  "operation": "list_materials",
  "kind": "knowledge",
  "limit": 50
}
```

供应商来源 `kind` 为 `supplier`。配置了密钥变量时附带 `Authorization: Bearer <密钥>`。15 秒超时、不跟随重定向、响应上限 256KB。域名必须加入白名单并解析到公网地址；本版本没有内网 CMS 直连适配。

适配服务返回：

```json
{
  "schemaVersion": 1,
  "items": [
    {
      "externalId": "supplier-product-001-front",
      "title": "角阀正面商品图",
      "type": "image",
      "sku": "JF-001",
      "body": "原系统提供的商品图说明",
      "url": "https://detail.1688.com/offer/123.html",
      "imageUrl": "https://images.example.com/products/JF-001.jpg",
      "rights": "authorized",
      "rightsNote": "示例授权编号，请替换为真实使用依据",
      "expiresAt": "2027-01-31"
    }
  ]
}
```

以上全部为协议示例，不是真实供应商素材或授权。

| 字段 | 规则 |
|---|---|
| externalId | 同一来源下稳定、唯一的编号；1–120 字符；用于幂等更新 |
| title | 必填，最长 160 字符 |
| type | `document` 或 `image` |
| sku | 图片必填；最长 120 字符；知识正文可留空表示通用知识 |
| body | 知识正文必填，最长 6000 字符；图片说明可选 |
| url | 供应商资料必填的原始来源 HTTPS 链接 |
| imageUrl | 图片必填的 HTTPS 原图地址，最长 2048 字符 |
| rights | `unknown`、`reference` 或 `authorized` |
| rightsNote | 授权依据或参考限制；`authorized` 必填；最长 500 字符 |
| expiresAt | 可选 `YYYY-MM-DD`；按北京时间当日结束判定失效 |

每次最多接收 50 项。接口应返回一个受控批次；**尚无自动分页、定时同步、增量游标或全库镜像**。缺失项目不会被自动删除，删除 / 撤权需要在本平台撤回审核。同步不会信任来源返回的审核状态：新增或内容变更后都回到待审核；相同内容保留原审核与版本。

知识库适配方负责把其文档或检索结果转成正文；内容平台负责返回原图地址和元数据；1688 适配方负责其官方授权、签名、接口权限及字段映射。平台不读取客户的浏览器登录状态。

## 3. 异常与版本处理

| 情况 | 行为 / 用户处理 |
|---|---|
| 缺字段、非法链接、无授权依据 | 表单就近提示，保留输入；不保存无效资料 |
| 同时编辑 / 审核旧版本 | 返回 409，重新打开当前资料后再确认 |
| 来源停用、过期、审核撤回、资料内容变化 | 旧目标引用不再可用于新调用或验收；回到资料页重新审核、选用或移除 |
| 目标正在生成时更换资料 | 目标版本增加；旧任务结果不写入新版本 |
| 引用在调用期间失效 | 在调用前、模型循环步骤间、结果写入前检查；拒绝失效结果，不作为成功交付 |
| 同步超时、认证错误、域名不允许 | 来源卡保留上次失败说明，原资料不变；修正配置后重试 |
| 一批数据中有无效项目或重复 externalId | 整批拒绝，不部分覆盖已有资料 |
| 连续点击同步 | 同一来源互斥；同步中禁止编辑连接配置 |
| 服务重启时正在同步 | 标为中断并允许重试；稳定 externalId 防止重复导入 |
| 目标已交付 / 验收阶段需要改资料 | 当前版本不可直接覆盖；新建跟进目标。审核撤回不会抹掉历史交付 |
| 静态 HTML / GitHub Pages 同步外部来源 | 明确提示需完整后端；仍可手动登记、审核和选用 |

## 4. 平台接口与存储

- `GET /api/sources`：来源和资料列表，包括可选状态说明。
- `POST /api/sources`、`PUT /api/sources/:id`：来源配置；更新传 `revision`。
- `POST /api/sources/:id/sync`：调用授权适配接口并导入受控批次。
- `POST /api/materials`、`PUT /api/materials/:id`：登记 / 编辑手工资料。
- `POST /api/materials/:id/review`：`revision`、`status`、`note`、`confirmed`。
- `POST /api/goals/:id/actions`：`kind: "references"`、`expectedVersion`、`confirmed: true`、`references: [{id, revision}]`。

以上接口沿用工作空间令牌与跨站修改校验。来源、资料、审核结果保存到 `.data/platform.json`；每次员工运行保存当次引用输入。仍是单工作空间、单进程版本，没有独立审核员身份和完整多租户权限。

## 5. 本版范围与后续对接

已实现：手工正文 / 链接登记、关键词检索、审核与有效期、通用 HTTP 连接同步、版本化目标引用、实际代码交付来源说明、免安装预览。

尚未实现：Dify / 飞书 / 指定 CMS 原生连接器、1688 官方 OAuth 与原生接口、图片文件托管、PDF / Office 解析、向量知识库、自动找图、图像内容识别、图片生成、自动授权判定。

下一步需要客户确认现有系统及接口权限，再做对应适配器与真实数据联调。当前通过 47 项自动化测试；真实后端与断网预览的资料登记、审核、选用、交付引用浏览器流程均已验证。HTTP 协议测试使用受控响应，尚无客户真实系统联调。
