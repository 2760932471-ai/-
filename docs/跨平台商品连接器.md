# 跨平台商品连接器

在「AI基础能力配置 → 跨平台连接器」选择来源账户和销售店铺。每个工作空间单独配置。美团联盟与美团是两个来源标识，分别为 `meituan_union` 和 `meituan`。闲鱼的销售渠道标识为 `xianyu`。1688 和淘宝分别使用 `1688` 和 `taobao`。

以下是**本工作台的服务商网关协议**。接入方负责将请求映射到已获准使用的平台 API，并依据商户实际资质、商品类目、授权渠道和履约条件返回结果。文中的餐券和价格仅用于说明字段。实际平台能力和类目资格以账户及相应开放平台文档为准。

## 接入选品来源

在「供应商接入」创建供应商来源，选择 HTTP，填写选品平台标识、适配服务的 HTTPS 地址与服务器密钥变量名。来源账户绑定在此网关配置上。POST 请求使用 JSON，并在配置密钥时使用 Bearer 验证。服务器需在 AGENT_ALLOWED_HOSTS 中允许网关域名。如需同步普通资料，网关可另外实现已有的 list_materials 协议。

查找候选时请求 `{"schemaVersion":1,"operation":"offer.search","platform":"meituan_union","query":"双人餐","limit":20}`。返回 `{"schemaVersion":1,"items":[...]}`。准备草稿及发布前请求 `offer.get`，以 `offerId` 代替 query 和 limit，返回 `{"schemaVersion":1,"item":{...}}`。

商品记录示例：

```json
{
  "id": "offer-42",
  "title": "示例双人餐",
  "priceFen": 9800,
  "currency": "CNY",
  "rights": "resale",
  "channels": ["xianyu"],
  "fulfillment": "顾客预约后到指定门店核销",
  "terms": "适用门店、预约要求、可用日期及退款条件由来源按实际商品完整返回",
  "validUntil": "2027-01-01T00:00:00+08:00"
}
```

`priceFen` 是来源报价，单位为人民币分。销售价由用户单独设置。来源需从授权数据读取 rights，推广商品返回 promotion。转售商品返回 resale、准许的目标渠道、履约方式、交易条款，以及有时限时的有效期。来源无法确认时返回 unknown。

## 接入销售店铺

在「店铺连接」添加销售账户，选择平台及服务商网关，填写店铺 ID、网关地址和凭据变量名。检查授权会调用 connection_status 并核对店铺 ID。具备新增商品发布能力的网关在 scopes 返回 listing.create。管理员可单独开启「允许确认后发布新商品」。

选定商品和销售价后先生成草稿。点击草稿上的确认发布按钮，系统会重新获取来源商品并核对授权与报价。配置或商品变化时需要重新准备草稿。通过后向销售网关 POST：

```json
{
  "schemaVersion": 1,
  "operation": "listing.create",
  "platform": "xianyu",
  "shopId": "目标账户标识",
  "idempotencyKey": "本次草稿标识",
  "sourcePlatform": "meituan_union",
  "offer": {"id": "offer-42", "...": "完整的上述商品记录"},
  "priceFen": 10900
}
```

网关需要根据货号取得类目、图片及平台要求的商品信息，检查发布资格，使用当前店铺的授权提交，并按 idempotencyKey 去重。实际确认已发布后，返回同一 shopId、schemaVersion 1、status 为 published 及非空字符串 listingId。超时、仅受理、回执缺少商品编号或进程中断，均保留为「结果待核对」，由操作者在店铺后台核对。

此版本覆盖选品到发布回执。订单接收、采购下单、券码发放、核销与退款对账尚待对接具体供应商的订单和履约接口。
