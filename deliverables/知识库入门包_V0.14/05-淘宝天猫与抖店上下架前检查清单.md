# 淘宝天猫与抖店上下架前检查清单
本文是接入与操作检查清单，不包含平台官方 API 参数，也不证明当前系统已获得发布权限。
## 授权准备
填写平台、店铺公开地址和店铺 ID。地址仅用于识别。淘宝/天猫与抖店分别按其官方开放平台申请应用或使用已授权服务商，核对授权对象、有效期和实际接口权限。
## 连接验证
后端保管密钥，界面只保存密钥环境变量名称。先调用只读接口核验返回的店铺 ID 与权限。测试成功不等于上架接口已实现。
## 上架前
核对商品归属、类目、品牌资质、标题、图片授权、属性、规格、价格、库存、运费、售后承诺及生效时间。保留修改前后对照。负责人批准明确的商品范围和动作。
## 下架前
确认下架原因、目标商品、未履约订单、在途活动和恢复安排。下架不等于删除商品，也不自动取消已有订单。
## 执行后
记录请求标识和平台响应，超时不得直接重复写入，应先查询平台状态。成功回执后读取商品状态核验；未知结果显示“待核验”，不能显示成功。
## 当前边界
系统尚未实现平台专属写入适配时，只允许准备草案和检查授权。禁止因为连接表单已保存而承诺自动接管店铺。
